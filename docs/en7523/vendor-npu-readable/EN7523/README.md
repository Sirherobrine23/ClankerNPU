# EN7523 md32rv readable firmware bundle

This subset contains the EN7523 variants from the full analysis bundle.

Read `../reconstruction/EN7523_CLANKER_DIFF.md` for a comparison of the vendor MT7915 firmware and ClankerNPU. Start with `../reconstruction/en7523_7915_core_reconstructed.c` and `../reconstruction/en7523_7915_high_value_routines.S` for high-confidence reconstructions, then inspect `../recovered/en7523_7915.pseudo.c.txt` and `.annotated.S` for the instruction-level view.

The binary inputs are copyright-protected vendor firmware supplied for static analysis. None of the outputs should be considered original vendor source or directly buildable replacements.
